# Retain document versions and registration acceptances

Each required site document has its own acceptance checkbox in parent registration. Record who accepted each document, the exact version accepted, and when acceptance occurred. Retain the accepted document version so replacing a site's document cannot alter the historical evidence of what the adult accepted.

An adult accepts each document version once per site, covering all their children at that site rather than repeating acceptance for each child. Acceptance at one site does not satisfy another site's documents.

Staff can add a site document with a title, a "Required acceptance" setting, and PDF content, Markdown content, or both. A document must contain at least one of those content formats. When both are present, show them together as one document with one acceptance checkbox covering the complete version. Changing either the Markdown or PDF creates a new version requiring fresh acceptance.

Registration must use the site's current required documents at submission. If required documents are added or changed while a parent completes the form, refresh the document section and require acceptance of the new or changed versions, preserving the details already entered.

When required site documents change, staff have an option to send the updated documents to applicable adults for fresh acceptance. Applicable adults are nominated parents or guardians responsible for accepting documents, each of whom must have an email address. Being linked to a child or authorised to collect does not automatically make an adult a document recipient. Adults whose linked children are all inactive at that site are excluded.

Each nominated parent or guardian must accept documents personally through their own emailed link. The registering parent's acceptance counts only for themselves and cannot satisfy another nominated adult's acceptance requirement.

After the registering parent submits and accepts the required documents personally, the registration can enter "Awaiting approval" while other nominated adults' acceptances are outstanding. Staff approval is blocked until every nominated parent or guardian has personally accepted all required documents. Staff must be able to see exactly whose acceptance is outstanding.

If required documents change while a registration awaits approval, every nominated adult must accept the latest required versions before staff can approve it. Previous acceptances remain in the history; new or changed required versions appear as outstanding, and staff can send fresh acceptance links.

For already approved and active children, outstanding acceptance of updated documents does not block collection, make the child inactive, or revoke collection permission. Show a clear outstanding-document flag to staff and allow them to resend acceptance requests. This differs from the latest-version acceptance requirement before initial registration approval.

Document acceptance uses a signed link emailed to the individual adult, with a seven-day expiry and a check against that recipient adult's date of birth. Five incorrect DOB attempts lock the link. Resending starts a fresh seven-day validity period and invalidates the previous link. Each link permits only that adult's document acceptance, without requiring an account.

The adult page can display outstanding documents and request a personal acceptance email. Acceptance then uses the same signed-link and adult-DOB flow, so an email-only adult-page session does not bypass the document verification check.

The adult originally invited by staff to register the child is document-responsible by default. The registering adult can nominate additional parents or guardians on the form, and staff can review and amend nominations before approval. Default responsibility follows the original invitee, rather than the ordering of adults on the form.
